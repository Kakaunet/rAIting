To use the rAItings, you must insert in your project's README.md, or in a file (which its name must be **rAIting_[insert rAIting here].md**) in the project's root directory, one of templates (of course modified to match your rAIting).\
Please copy the text (from this file or from the rAItings file) in "Code" mode, so that links and formatting are kept.

# If your rAIting does not have a modifier, use the following template:

## [rAIting](https://github.com/Kakaunet/rAIting) [insert rAIting here]
[insert rAIting level description here]

# If your rAIting does have one modifier, use the following template:

## [rAIting](https://github.com/Kakaunet/rAIting) [insert rAIting here]
[insert rAIting level description here]\
[insert rAIting modifier description here]

# If your rAIting does have multiple multiple modifiers, use the following template instead:

## [rAIting](https://github.com/Kakaunet/rAIting) [insert rAIting here]
[insert rAIting level description here]
### [insert modifier 1 here]
[insert rAIting modifier 1 description here]
### [insert modifier 2 here]
[insert rAIting modifier 2 description here]
### [insert modifier ... here]
[insert rAIting modifier ... description here]

# Here are some examples:

## [rAIting](https://github.com/Kakaunet/rAIting) B
AI was used for fixing minor errors and optimizing/adapting some minor parts of the code, but did not do major changes to the code, and did not affect asset creation, or anything that does not relate to code.

## [rAIting](https://github.com/Kakaunet/rAIting) D.r
AI was used to generate some minor to medium parts of the code that were not necessarily too difficult for the coders [modifier [u](#u---unknown) changes this]. AI was also slightly used in asset creation or anything that is designed to be viewed by the user (images, UI designs, etc).\
This project was only made for recreational purposes, and is not intended to be a serious project.

## [rAIting](https://github.com/Kakaunet/rAIting) F.l-u
AI was used for a very large part of the project, including but not limited to: code, assets, UI, APIs, or anything at all related to the project.
### l - Limitations
A large portion of the AI used was due to limitations with what the project creator could do. For example, it could be: unable to access or use required resources, legally restricted from using required resources, etc. This modifier only applies for _digital_ limitations: disabilities, absence of basic hardware (mouse, keyboard, and the absolute basics of an usable electronic device), and etc, do not apply to this modifier.
### u - Unknown
AI was used due to the creators' knowledge limitations about coding a certain something.
